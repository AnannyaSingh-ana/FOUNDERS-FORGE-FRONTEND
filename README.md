# 🚀 Founders' Forge - Frontend

Frontend for **Founders' Forge**, a multi-agent AI startup consulting platform.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Features

- Clean startup idea submission interface
- Dynamic consulting report dashboard
- Responsive UI
- API integration with FastAPI backend
